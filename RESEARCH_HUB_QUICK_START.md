# Research Hub - Quick Start Guide

## 🚀 Getting Started

The Research Hub is now live with a completely redesigned, task-oriented interface inspired by SciSpace.

## What's New?

### 1. Task-Oriented Landing Page
When you visit the Research Hub, you'll see:
- **Prominent search bar** at the top
- **6 task cards** to guide your research
- **Popular searches** for quick access

### 2. Six Research Tasks

#### 🔍 Find Similar Trials
**Use when**: You want to find clinical trials similar to your research
**What it does**: Searches ClinicalTrials.gov and CTRI India
**Best for**: Researchers looking for comparable studies

#### 📄 Literature Review
**Use when**: You need to review research papers and studies
**What it does**: Searches PubMed and Perplexity AI
**Best for**: Conducting systematic literature reviews

#### ✏️ Design Protocol
**Use when**: You want to create a new trial protocol
**What it does**: Takes you directly to Protocol Builder
**Best for**: Starting a new clinical trial

#### 📈 Analyze Trends
**Use when**: You want to understand research patterns
**What it does**: Searches all sources, shows AI Insights
**Best for**: Understanding the research landscape

#### ⚖️ Compare Studies
**Use when**: You need to compare multiple trials
**What it does**: Searches ClinicalTrials.gov for comparison
**Best for**: Comparing trial designs and outcomes

#### 💡 Get AI Insights
**Use when**: You want AI-powered research summaries
**What it does**: Uses Perplexity AI for web search
**Best for**: Getting intelligent, current information

## How to Use

### Method 1: Choose a Task (Recommended)
```
1. Click on a task card (e.g., "Find Similar Trials")
2. Search view opens with pre-configured sources
3. Enter your search query
4. View results organized by tabs
5. Bookmark items you want to save
6. Click "Back to Tasks" to start over
```

### Method 2: Direct Search
```
1. Type directly in the search bar on landing page
2. Press Enter or click Search button
3. View results immediately
4. Refine with source selection if needed
5. Bookmark items you want to save
```

### Method 3: Quick Actions
```
1. Click a popular search chip
2. Get instant results
3. Explore and bookmark
```

## Understanding Results

### Tabs
- **Clinical Trials (count)** - Trials from ClinicalTrials.gov and CTRI India
- **Research Papers (count)** - Papers from PubMed
- **Perplexity AI** - AI-powered web search insights
- **AI Insights** - Analysis and recommendations

### Result Cards
Each result shows:
- **Title** - Study or paper title
- **ID** - NCT number or PMID
- **Bookmark icon** - Click to save (filled = saved, outlined = not saved)
- **Chips** - Phase, status, enrollment, SOURCE
- **Details** - Condition, intervention, authors, etc.
- **Actions** - View details, use as template, export, cite

### Source Badges
Every result shows its source:
- **Purple badge** - ClinicalTrials.gov, CTRI India
- **Blue badge** - PubMed, Perplexity AI

## Bookmarking

### How to Bookmark
1. Click the bookmark icon on any result card
2. Icon fills in when bookmarked
3. Click again to remove bookmark

### Why Bookmark?
- Save interesting studies for later
- Build a collection of relevant research
- Easy reference during protocol design

## Source Selection

### Available Sources
- **ClinicalTrials.gov** - US clinical trials (50 results)
- **PubMed** - Biomedical literature (50 results)
- **CTRI India** - Indian clinical trials (coming soon)
- **Perplexity AI** - AI web search (active)

### How to Select
1. In search view, look for source chips
2. Click to toggle on/off
3. Selected = filled color
4. Not selected = outlined

### Smart Pre-Configuration
Each task automatically selects the best sources:
- Find Trials → ClinicalTrials.gov + CTRI India
- Literature Review → PubMed + Perplexity AI
- Analyze Trends → All sources
- Get AI Insights → Perplexity AI

## Common Workflows

```
1. Click "Find Similar Trials"

```

```

```


## Troubleshooting

### No Results?
- Check if sources are selected (chips should be filled)
- Try broader search terms
- Enable more sources

### Perplexity AI Not Working?
- Verify source chip is selected
- Check internet connection
- Try again in a moment

### Bookmarks Not Saving?
- Bookmarks persist during session
- Will be saved to database in future update
- For now, export important items

### Page Loading Slowly?
- Check internet connection
- Try refreshing page
- Disable unused sources
