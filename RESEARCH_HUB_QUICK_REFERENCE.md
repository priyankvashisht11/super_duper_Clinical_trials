## 🔧 Troubleshooting

**No results?**
- Check if sources are selected (chips should be filled)
- Try broader search terms
- Enable more sources

**Perplexity AI not working?**
- Check if chip is selected
- Verify API key in backend/.env
- Check console for errors

**Source badges not showing?**
- Refresh page
- Clear browser cache
- Check if using latest version
